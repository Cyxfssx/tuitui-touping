# 推推投屏 · USB 个人版（Windows 测试版）

这是桌面源码丢失后的重新实现，使用 Python、Tk 和 tkinterdnd2，不依赖 Qt；与旧推推投屏的 EXE、配置分开。它复用原版定制 scrcpy、ADB 和推推2图片桥接器，不能声称保留原桌面程序的原始函数与事件绑定。

## 启动

本机双击 `启动推推个人版.bat`。其他 Windows 电脑需要 Python 3.12：

```bat
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements-native.txt
```

将原推推投屏安装包中的 `engine` 文件夹完整复制为项目根目录的 `tuitui-engine`，同时保留 `assets/tuitui2-scanner.jar`。不能用官方原版 scrcpy 替代该定制引擎：它提供 `--text-via-clipboard` 和 `--no-clipboard-images`。当前引擎和原图片桥接器的完整源码尚未恢复。使用个人版前请退出旧推推投屏及其桥接进程，避免多个程序同时处理快捷键。

## 设备与模式

- 手机通过 USB 连接、开启 USB 调试并授权电脑。设备列表和投屏窗口标题显示自定义名称；序列号仍用于内部识别，不显示在列表或标题中。修改名称后点击“更新名称”，正在运行的投屏窗口也会立即更新。
- “一键 USB 连接”对选中且已授权的设备启动独立投屏；投屏中按钮变为“停止投屏”。刷新按钮重新检测 ADB 设备。未授权设备需要先在手机确认授权。
- 默认启用精简模式；右上角“高级设置”或取消勾选精简模式，会显示画面设置和文件传输。首次升级到新界面时默认为精简模式，之后记住设置。
- 配置保存在 `%APPDATA%\TuiTuiPersonal`，独立于原版。可勾选“保持唤醒”（scrcpy 的 `--stay-awake`）、“自动息屏”（启动投屏时的 `--turn-screen-off`）和“记住窗口位置”。这些画面选项在下一次启动投屏生效。窗口未最小化时约每 1.5 秒记录位置，点击停止或关闭程序前也会记录；刚移动窗口后立刻在投屏窗口右上角关闭，最后一次移动可能尚未记录。
- 启用“自动重连”时，仅重试由本程序启动且未手动停止的投屏，设备不在线时等待 USB 设备回来，失败时逐步延长重试间隔。手动停止或关闭投屏窗口后不会主动重开。程序退出后不会自动连接。

## 文件与图片

- 高级面板支持拖放或多选文件，只传到当前设备。支持逐项暂停、继续和取消；暂停在当前 2 MiB 分块的传输边界生效。队列最多保留 128 项，可清理已结束任务。
- 文件按分块传输到同目录的临时文件，全部完成后才替换最终目标；同名目标会被覆盖。取消通常会清理临时文件，若 USB 意外断开，手机上可能残留 `.tuitui-*.part` 或 `/data/local/tmp/tuitui-*.chunk`。程序重启或设备断开后不支持断点续传。
- Windows 中文/韩文输入法上屏使用原版定制投屏引擎的 SDK 键盘及手机文字剪贴板；输入可能改变手机剪贴板。手机选中推推2输入法（`com.chatmirror.warmclone2`）后，在本程序启动的投屏窗口按 Ctrl+V 可以提交图片。聊天应用必须支持输入法图片接口；成功表示应用接受了请求，不代表聊天消息已发送。

## 验证及限制

- 已在 SM-A376B 上验证投屏进程异常退出后的自动重启和手动停止后不重试、窗口位置捕获、真实文件上传期间暂停/继续与哈希一致、取消后原有同名文件未被覆盖。
- 一键 USB 检测、名称显示和精简/高级切换已验证；分块任务的暂停与取消有独立自动测试。图片 Ctrl+V 使用此前真机验证过的图片桥接机制；本轮没有重复向聊天发送测试图片。
- 自动重连用进程异常退出模拟验证，尚未进行实际拔插 USB 验证。保持唤醒和自动息屏已验证对应命令行参数，未在本轮改变手机屏幕状态验证。部分高 DPI、文件名、安卓厂商系统和网络异常场景仍需验证。
- 旧版桌面源码未恢复，个人版并非原版完整替代品；未重建录屏、下载、逐任务进程级立即暂停、多设备群控等功能。拖放的处理路径已测试，系统资源管理器实际拖放仍需验证。暂停和取消可能需要等待当前分块结束。

## 源码

`tuitui_personal_main.py` 入口；`tuitui_personal/ui.py` 界面；`backend.py` 设备和投屏；`transfers.py` 逐项传输队列；`windows.py` 窗口位置；`hotkeys.py` 图片快捷键；`tests/test_personal_transfers.py` 为传输队列测试。
